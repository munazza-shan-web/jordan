# Jordan Bryant Portfolio

Static site: `index.html`, `images/`, `Jordan-Bryant-CV.pdf`.

## Publish on GitHub Pages
1. Create a repo and upload everything inside this folder to the repo root.
2. Settings > Pages > Deploy from a branch > `main` / root.
3. The site goes live at `https://<username>.github.io/<repo>/`.

To update the CV, replace `Jordan-Bryant-CV.pdf` keeping the same name.
